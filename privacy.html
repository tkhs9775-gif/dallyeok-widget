달력위젯 개인정보처리방침

시행일: 2026-11-25

쓰는 데이터

Google 캘린더 권한 calendar.app.created로, 이 앱이 만든 "비서" 캘린더의 일정(제목·날짜·시각)만 읽고 씁니다. 다른 캘린더와 그 밖의 Google 데이터에는 접근하지 않습니다.

저장 위치

일정은 사용자 PC(%APPDATA%\달력위젯)와 사용자 본인의 Google 캘린더에만 저장됩니다. 로그인 토큰은 Windows 자격 증명 관리자에 저장됩니다. 개발자 서버나 제3자에게 보내지 않습니다.

공유·판매

어떤 데이터도 다른 사람에게 공유하거나 판매하지 않습니다. 광고에 쓰지 않습니다.

삭제

Windows 자격 증명 관리자에서 달력위젯-google 항목을 지우고, Google 계정 → 타사 앱 연결에서 달력위젯 접근을 해제하면 연결이 끊깁니다.

Google API에서 받은 정보의 사용은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 따릅니다.
